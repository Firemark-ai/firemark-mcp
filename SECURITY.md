# Security

Report a security issue in the Firemark MCP server or this repository to **support@tenpointlabs.com** with "Security" in the subject. Please do not open a public issue for it.

Firemark's only MCP server address is `https://app.tryfiremark.com/mcp`. Firemark does not publish any other server address, package or install script. If you find one claiming to be Firemark, tell us.
